## 🔮 Overview: The Ghost in the Machine

Every night between 12:00 AM and 04:00 AM (**The Witching Hour**), smart home thermistors, EMF probes, and environmental micro-sensors record subtle, unexplained fluctuations: sudden 8°C localized cold spots, micro-seismic vibrations along water pipes, and electromagnetic spikes. Conventional home automation frameworks dismiss these as "sensor noise."

**Ghost in the Sensor** turns this paradigm on its head. Using open-weight AI (**Google Gemma 2**), it correlates nocturnal telemetry streams into an investigative paranormal dossier:
1. **Spectral Anomaly Detection**: Correlates multi-sensor inputs (thermal drop + EMF surge + acoustic frequency).
2. **Entity Classification**: Categorizes manifestations into *Poltergeist Kinetic Cores*, *Cryogenic Phantasms*, *Electro-Specters*, or *Ancestral Luminaries*.
3. **Electronic Voice Phenomenon (EVP) Synthesizer**: Reconstructs sub-audible acoustic shockwaves into decoded spirit whisper audio using browser Web Audio synthesis.
4. **Día de los Muertos Remembrance**: Recognizes gentle thermal warming and harmonic resonance during Día de los Muertos, generating heartfelt remembrance poems (*calaveritas*) and ofrenda protocols.

## 💡 Why Open Innovation Matters

The Hacktoberfest prompt asks: *Where does an open-based approach work better than a closed one?*

1. **🔒 Absolute Privacy for Sacred Spaces**:  
   Smart home logs and bedroom acoustics should never be shipped to a corporate cloud API. By running open-weight **Gemma 2** locally or on edge infrastructure, your nocturnal telemetry never leaves your device.
2. **🕯️ Works with the Lights (and Internet) Off**:  
   True paranormal investigations happen in abandoned buildings, off-grid cabins, or during power outages. Closed APIs fail when connectivity drops; **Ghost in the Sensor** operates 100% offline.
3. **⚡ Zero API Tolls & Censorship-Free Lore**:  
   Closed proprietary APIs frequently censor or sanitize spooky, gothic, or superstitious narratives. Open weights grant full creative freedom without recurring token costs.

## 🛠️ Architecture & Tech Stack

- **AI Core:** Google Gemma 2 Open-Weights (Forensic Reasoning & Lore Synthesis)
- **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons, Canvas 360° Phosphor Radar
- **Audio Synthesizer:** Native Web Audio API EVP sound synthesis (432Hz spirit bandpass filter)
- **Backend:** Node.js, Express, Open-source DSP Anomaly Correlator
- **Deployment:** Render Blueprint (`render.yaml`)

## 🚀 Quickstart & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/yashselokar2025/ghost-in-the-sensor.git
cd ghost-in-the-sensor
```

### 2. Start the Backend
```bash
cd server
npm install
npm start
```
*Backend runs on `http://localhost:5000`*

### 3. Start the Frontend
```bash
cd ../client
npm install
npm run dev
```
*Open `http://localhost:5173` in your browser.*
